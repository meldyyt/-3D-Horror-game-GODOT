# Квартира 47 (Apartment 47)

3D психологический хоррор от первого лица в атмосфере PSX / Low-Poly Horror.

---

## 1. Сведения о проекте
- **Название:** Квартира 47 / Apartment 47
- **Версия движка:** Godot Engine 4.x (протестировано на Godot 4.7.x)
- **Язык разработки:** GDScript
- **Рендерер:** Forward+
- **Жанр:** 3D First Person Psychological Horror / Loop Horror

---

## 2. Управление
- **W, A, S, D** — Движение (Вперёд, Влево, Назад, Вправо)
- **Мышь** — Обзор камеры
- **Left Shift** — Бег (Sprint)
- **Left Ctrl / C** — Приседание (Crouch)
- **E** — Взаимодействие (открыть дверь, взять предмет, прочитать записку)
- **F** — Включение / выключение фонарика
- **TAB / I** — Открыть / закрыть инвентарь (12 ячеек, осмотр предметов)
- **ESC** — Пауза / освобождение курсора мыши (клик ЛКМ возвращает захват)

## 4. Как запустить проект

### Способ 1: Через Godot Editor
1. Запустите **Godot Engine 4.x**.
2. В окне управления проектами нажмите кнопку **«Импортировать»** (Import).
3. Укажите путь к папке: `C:\Horror game\project.godot`.
4. Нажмите **«Импортировать и редактировать»** (Import & Edit).
5. Нажмите клавишу **F5** (или кнопку «Играть» в правом верхнем углу), чтобы запустить проект.

### Способ 2: Через командную строку
Выполните команду в терминале:
```powershell
& "C:\Program Files (x86)\Steam\steamapps\common\Godot Engine\godot.windows.opt.tools.64.exe" --path "C:\Horror game"
```

## 5. Текущий статус (Version 0.3.5)
В проекте реализованы ключевые хоррор-механики психологического выживания и петлевая система:
- **Петлевой менеджер (LoopManager):** Data-driven архитектура на ресурсах `LoopData` с динамическим управлением освещением, туманом, звуками и объектами.
- **Пространственные триггеры (LoopTrigger):** невидимые портальные зоны на обоих концах коридора, бесшовно возвращающие игрока в начало через мягкое моргание экрана (`ScreenFader`).
- **5 последовательных циклов этажа:**
  - **Цикл 01:** обычный коридор, дверь 47 заперта.
  - **Цикл 02:** свет тускнеет, учащается мерцание ламп.
  - **Цикл 03:** звуки плача из-за двери 45, дверь подсобки сама распахивается настежь.
  - **Цикл 04:** посреди пустого коридора появляется обугленная детская игрушка и детский рисунок.
  - **Цикл 05:** перед дверью 47 появляется высокий силуэт Жильца (The Resident), бесследно исчезающий при приближении или взгляде.
- **Инвентарь и предметы:** визуальный хоррор-инвентарь на 12 ячеек (`TAB` / `I`), 3D-модель ключа, батарейки для подбора.
- **Фонарик и батарейки:** ограниченный заряд, мерцание и затухание при низком заряде, подбираемые батарейки на уровне.
- **Выносливость и физиология:** спринт расходует силы, ускоренное восстановление в приседе, истощение с учащенным дыханием.
- **Динамический хоррор-звук:** тяжелое дыхание при усталости, учащенное сердцебиение при приближении монстра или фазе погони.
- **Стелс и Неуязвимый Сталкер (AI):** 4 состояния (`PATROL`, `INVESTIGATE`, `CHASE`, `ATTACK`), реакция на шум бега и луч света. Монстра нельзя убить (никаких полосок HP и оружия), при поимке — скример и перезапуск петли.
- **Минималистичный затухающий HUD:** полоски выносливости и батарейки плавно проявляются только когда они активны/расходуются, не загромождая экран.
